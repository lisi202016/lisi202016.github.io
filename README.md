# Сайт Лиси

https://lisi202016.github.io/

Готовая сборка сайта для GitHub Pages. Исходный код — в репозитории
[lisi202016/lisi-site](https://github.com/lisi202016/lisi-site).

- **Панель владельца:** https://lisi202016.github.io/panel/ — вход по токену GitHub.
- `content.json` — всё содержимое сайта; его меняет панель.
- `uploads/` — треки и картинки, загруженные через панель; `uploads/thumbs/` — их
  уменьшенные копии для сеток.
- `config.js` — куда отправляется анонимная статистика переходов.

Руками здесь ничего править не нужно: каждое сохранение в панели — отдельный
коммит, любую старую версию можно вернуть через историю.
